# aneirin_Brain — Legacy / Archived Prototype

> **Status: legacy, no longer under active development.**
>
> This repository preserves an earlier experimental memory-system implementation and its development history. Active development has moved to **Nocturne / 夜航**, a separately redesigned memory architecture.

## Project lineage

`aneirin_Brain` began as an experimental modification/fork of **Ombre Brain** and was extended with additional memory, retrieval, relationship, lifecycle, and service-layer experiments.

As the design evolved, the newer Nocturne work moved away from the original architecture and is being separated into its own repository rather than continuing to present this repository as the current implementation.

This repository is retained for:

- historical development context;
- legacy implementation reference;
- migration and compatibility testing;
- baseline/failure analysis for the successor system;
- preserving attribution and commit history.

It should **not** be treated as the current Nocturne implementation or as a production-ready memory backend.

## Successor

**Nocturne / 夜航** is the successor project. It uses a redesigned architecture centered around explicit provenance, non-destructive migration, semantic continuity, structured memory entities, and staged retrieval/lifecycle mechanisms.

A link to the standalone Nocturne repository will be added here after the new repository is created and its code-lineage audit is complete.

No new feature development is planned for this repository. Changes should be limited to archival notes, security-critical fixes, migration compatibility, or documentation needed to understand the legacy system.
